\app{} meets the project's objectives. Engineers can rebuild a substation one-line
diagram over its original drawing, record each device's coil and motor data, and have
the protection zones proposed from the wiring. They can then review and verify each
zone and obtain the momentary current every DC supply must deliver, along with a PDF
report showing how each figure was reached.

Throughout, the emphasis has been on results that an engineer can check and trust:
\begin{itemize}
  \item every stage total shows its arithmetic;
  \item zones must be verified before a study is complete, and the verification
        lapses when the drawing changes;
  \item incomplete studies are clearly marked provisional.
\end{itemize}
An independent recalculation of all 13 provided layouts matched the tool exactly, and
288 automated tests, with more than 34{,}000 generated cases, run on Windows and Linux
whenever the code changes. The sponsor reviewed the layouts and confirmed that they are
correct.

The tool is delivered as a portable Windows application that needs no installation or
internet connection. The most promising next step is automated recognition of
imported drawings, which would remove the most time-consuming part of a study.
